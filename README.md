# Hybrid/Wk — 16-Wochen-Block

Hybrid-Training als iPhone-Web-App: 5 × Kraft und 3 × Laufen pro Woche, vier Monate
durchprogrammiert, mit Session-Runner, Pausentimer, Bestleistungen und Progression,
die aus deinen eigenen Zahlen rechnet.

## Installieren

1. GitHub → **New repository** → `hybrik-wp` → Public → *Create*
2. **Add file → Upload files**: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-512.png`
3. **Settings → Pages → Branch: main → Save**
4. `https://DEINNAME.github.io/hybrik-wp/` in **Safari** öffnen
5. Teilen → **Zum Home-Bildschirm**

Läuft danach im Vollbild, offline, alles lokal gespeichert.

## Der Block

| Block | Wochen | Kraft | Laufen |
|---|---|---|---|
| 1 Base | 1–4 | 8–10 Wdh, Volumen | 17–21 km, Strides und erstes Tempo |
| 2 Build | 5–8 | 6–8 Wdh, Gewicht hoch | 22–25 km, Intervalle dazu |
| 3 Strength | 9–12 | 5–6 Wdh, schwer | 26–30 km, längster Lauf 15 km |
| 4 Peak | 13–16 | 3–5 Wdh, Spitze | 31 km Peak, dann 5 km auf Zeit |

Jede vierte Woche ist Deload: Sätze runter, Gewicht runter, Laufumfang zurück.

## Die Woche

| Tag | Kraft | Laufen |
|---|---|---|
| Montag | Push — Bankdrücken schwer | Easy Run |
| Dienstag | Lower A — Squat + Beinpresse | — |
| Mittwoch | Pull — Klimmzüge, Rudern | Tempo oder Intervalle |
| Donnerstag | frei | — |
| Freitag | Lower B — Deadlift | — |
| Samstag | Full Body, moderat | Long Run |
| Sonntag | Reset | — |

## Progression

Im Setup trägst du deine Arbeitsgewichte ein (Bank, Squat, Beinpresse, Deadlift,
Overhead Press) und dein lockeres Lauftempo. Daraus rechnet die App jede Woche
Zielgewichte und alle Laufpaces. Nach Woche 16 trägst du die neuen Werte aus der
Testwoche ein und startest den nächsten Block bei Woche 1.

## Finisher

Jede Krafteinheit endet mit einem CrossFit-Finisher im klassischen Format — EMOM,
AMRAP oder For Time, 8 bis 12 Minuten. Jeder Finisher hat eine RX- und eine Scaled-
Variante; umschalten geht im Finisher selbst oder global im Setup. Ergebnis eintragen
(Runden, Zeit), es landet im Verlauf und wird beim nächsten Mal zum Benchmark.

| Tag | Format | Inhalt |
|---|---|---|
| Montag | EMOM 10 | Burpees / KB Swings im Wechsel |
| Dienstag | AMRAP 8 | Wall Balls, Box Jumps, Rudern |
| Mittwoch | 5 Runden | Ring Rows, KB Swings, Hollow Rocks |
| Freitag | For Time | 21-15-9 KB Swings und Box Jumps |
| Samstag | AMRAP 12 | Cindy — Klimmzüge, Push-ups, Air Squats |

In Deloadwochen läuft der Finisher automatisch mit halber Rundenzahl.

## Übungen tauschen

Jede Übung hat vier passende Alternativen für dieselbe Muskelgruppe — Hantelbank belegt,
Gerät kaputt, Schulter zwickt. Tippe auf ⇄ neben der Übung oder auf "Tauschen" im
Session-Modus. Sätze und Wiederholungen bleiben, das Zielgewicht kommt danach aus
deinem Verlauf. Aktive Tauschungen stehen im Setup und lassen sich dort zurücknehmen.

## Session-Modus

Übung antippen → Vollbild. Gewicht und Wiederholungen pro Satz eintragen, Häkchen
setzen, Pausentimer startet automatisch mit der zur Übung passenden Zeit. RPE pro
Übung, Sessiondauer und Fortschritt laufen oben mit. Am Ende werden Volumen und
neue Bestleistungen gespeichert.
